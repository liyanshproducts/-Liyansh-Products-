# LIYANSH PICKLES Website

A free, mobile-friendly product catalogue website.

## Files
- index.html — complete website
- style.css — design and responsive layout

## Important before publishing
1. Replace the sample prices/products with your real details.
2. Replace the WhatsApp links with your WhatsApp number in `index.html`.
   Example: `https://wa.me/919876543210`
3. Replace the location and shipping information.
4. To add real product photos, replace each emoji product-image block with an `<img>` element.

## Free publishing
You can publish this site for free using GitHub Pages or another static-site host.
